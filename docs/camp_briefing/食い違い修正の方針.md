# 【今朝のシグナル】とBotデータの食い違い　修正の方針（2026-09-29）

対象：discord-ai-team（PC上。`C:\Users\edavi\discord-ai-team`）。このリポジトリ側の修正は不要。

## 食い違い①　コスモ・バイオ（3386）が🎯なのに、仮想売買では「見送り」

| | 【今朝のシグナル】（AIチーム） | Botデータ（latest_scan.json） |
|---|---|---|
| 表示 | 🎯 1. コスモ・バイオ | ⏸ 仮想エントリーの対象外 |
| 判定基準 | 複合スコア75点以上だけ | 75点以上 **かつ** 業種内モメンタム（`sector_relative.momentum_ok`）がtrue |

- 原因：AIチーム側が `sector_relative.momentum_ok` を見ていない（データには入っている）
- 3386.T は `rel_ret60 = -7.1%`（同業種平均より60日リターンが低い）→ `momentum_ok: false`

### 修正の過程
1. PCのClaude Codeで、discord-ai-team の「本日の候補一覧」を作っている箇所を探す
2. 🎯の条件に `sector_relative.momentum_ok is not False` を追加（データ不足でNoneの銘柄は落とさない＝Bot本体と同じ扱い）
3. 条件を満たさない75点以上は **⏸「勢い待ち」** 表示にする（2026-09-29 ユーザー決定。👀には格下げしない）
4. 9/29の latest_scan.json で試し実行（Discordには投稿しない）→ 表示を確認
5. 翌朝の実投稿で確認

### 予想される結果（9/29のデータの場合）
- コスモ・バイオ：🎯1位 → ⏸勢い待ち
- 🎯の銘柄が、500万円の仮想運用で実際に買っている銘柄と一致する（13銘柄）
- 会員さんの「1位なのに？」という混乱がなくなる
- リスク：小さい（表示ルールの変更だけ。点数計算は変えない）

## 食い違い②　東武住販（3297）「売上と利益が前年を下回る」vs「EPS増加 ✅」

| | 見ている期間 | 値 |
|---|---|---|
| AIチーム（環・凪） | 直近の四半期累計（前年同期比）と推定 | 売上 56.7億→52.5億（−7%）、営業利益 2.33億→2.24億（−4%）、純利益 1.53億→1.55億（+1%） |
| Botのカード | 通期の1株利益（3期） | 78.5 → 126.6 → 145.8円（増加） |

- 原因：どちらも間違いではなく **期間の違い**。ただし会員さんからは矛盾に見える
- AIチームがどのデータを使っているかは、PC側のコードで確認が必要（上の表は推定）

### 修正の過程
1. AIチームに渡している業績データの出どころと期間を確認
2. プロンプト（またはデータ）に期間ラベルを付ける（例：「直近四半期累計・前年同期比」「通期EPS」）
3. コメントに期間を必ず書かせる
4. 試し実行 → 翌朝の実投稿で確認

### 予想される結果
- コメント例：「直近の四半期は売上が前年同期比−7%と減速。ただし通期の1株利益は3期連続で増加」
- 矛盾に見えなくなり、コメントの説得力が上がる
- リスク：小（プロンプト変更のため、言い回しが多少変わる）
