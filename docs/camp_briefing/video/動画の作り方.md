# 説明会動画の作り方（Windows PC・ステップバイステップ）

スライド画像に読み上げ音声を付けて、1本の動画（約40分・mp4）にします。
作業時間の目安：初回30分（準備込み）、2回目以降は5〜10分。

---

## 0. 準備するもの（初回だけ）

### ① このフォルダをPCにコピー
`docs/camp_briefing/video` フォルダを丸ごと、PCの分かりやすい場所に置きます。
例：`C:\Users\edavi\camp_video\`

中身はこうなっています：
```
video\
  make_video.py      … 動画を作るプログラム
  slides\            … スライド画像（slide01.png〜slide33.png）
  narration\         … 読み上げる台本（slide01.txt〜slide33.txt）
  slide_titles.json  … チャプター（目次）用のタイトル
```

### ② Python が入っているか確認
1. スタートメニューで「cmd」と入力 →「コマンド プロンプト」を開く
2. `python --version` と入力して Enter
3. `Python 3.xx.x` と出ればOK（discord-ai-team を動かしているPCなら入っています）

### ③ ffmpeg が入っているか確認
1. 同じコマンドプロンプトで `ffmpeg -version` と入力して Enter
2. `ffmpeg version ...` と出ればOK（デイトレ動画作成で使っているので入っているはずです）
3. 「認識されていません」と出たら：`winget install Gyan.FFmpeg` を実行 → コマンドプロンプトを開き直す

### ④ 読み上げ音声のツールを入れる
```
pip install edge-tts
```
Microsoft の無料の読み上げ音声（インターネット接続が必要）です。

---

## 1. 動画を作る（基本）

1. コマンドプロンプトで、フォルダに移動します
   ```
   cd C:\Users\edavi\camp_video
   ```
2. まず **最初の3枚だけ** で試します（1〜2分で終わります）
   ```
   python make_video.py --only 1-3
   ```
3. `output\camp_briefing_video.mp4` を開いて、声の速さ・読み方を確認
4. 問題なければ全部作ります（10〜20分かかります）
   ```
   python make_video.py
   ```
5. 完成：`output\camp_briefing_video.mp4`
   あわせて `output\chapters.txt`（YouTube概要欄に貼るチャプター）もできます

---

## 2. 好みに合わせて変える

| やりたいこと | コマンド |
|---|---|
| 女性の声にする | `python make_video.py --voice ja-JP-NanamiNeural` |
| 話す速さを上げる | `python make_video.py --rate +15%` |
| 声を変えて作り直す | 上のコマンドに `--force` を付ける（作成済みの音声を作り直す） |
| VOICEVOXの声にする | VOICEVOXアプリを起動した状態で `python make_video.py --engine voicevox --speaker 13` |
| 音声なしで流れだけ確認 | `python make_video.py --engine silent` |

※ VOICEVOXを使う場合は、動画の説明欄に「VOICEVOX:（キャラ名）」のクレジット表記が必要です。

---

## 3. 読み方がおかしい所を直す

`narration\slideXX.txt` をメモ帳で開いて、ひらがな・カタカナに書き換えて保存 → `--force` を付けてそのスライドだけ作り直します。
```
python make_video.py --only 12 --force
python make_video.py
```
（2行目で全体をつなぎ直します。作成済みの音声は再利用されるので速く終わります）

---

## 4. 自分の声で録音したい場合（おすすめ）

YouTubeで収益化を目指すなら、**ご本人の声**が一番視聴維持率が上がります。

1. スマホのボイスメモ等で、スライドごとに台本（`narration\slideXX.txt`）を読んで録音
2. ファイル名を `slide01.m4a`, `slide02.m4a` … にして `audio\` フォルダに入れる
   （mp3 / wav / m4a どれでもOK。一部のスライドだけでもOK）
3. `python make_video.py` を実行 → 録音があるスライドは録音を、ないスライドは読み上げ音声を使います

---

## 5. スライドを修正した場合

1. PowerPoint で `camp_briefing.pptx` を修正
2. 「ファイル」→「エクスポート」→「ファイルの種類の変更」→「PNG」→「すべてのスライド」
3. 出てきた `スライド1.PNG`〜 を `slides\` フォルダに入れる（元の slide01.png 等は削除）
4. 台本を変えた場合は `narration\slideXX.txt` も直す
5. `python make_video.py --force`

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `edge-tts が入っていません` | `pip install edge-tts` |
| `ffmpeg が見つかりません` | 手順0-③ |
| `VOICEVOXに接続できませんでした` | VOICEVOXアプリを起動してから再実行 |
| 途中で止まった | もう一度同じコマンドを実行（作成済みの音声は再利用されます） |
